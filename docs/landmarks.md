# Landmark dressing checklist — Middle-earth

Generated by `npm run build:world` from `scripts/worlds/middle-earth.dressings.ts`. Edit that file, not this one.

Each landmark has a **setting** (written from the books), a **ground** override that recolours the terrain within its radius, a **vegetation** override (density, palette, flowers) and a list of procedural **set pieces** placed relative to the landmark. See `src/dressing/` for how they render.
